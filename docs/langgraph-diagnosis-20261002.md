# 2026-10-02 第三轮 GUI 停止原因排查

最初按“先排查”读取运行记录、重放模型请求并对比原图；下文保留当时的证据，文末记录用户随后授权的修复。

## 已确认的停止路径

运行目录：`output/langgraph_gui/20261002-112140-motion-fix/`。

第 4 轮 `match_grasp` 连续两次结果校验失败，随后抛出 `CapabilityError: match_grasp: ValidationError, status=None`。实际只执行了 `stow → turn_left(0.2) → turn_right(0.3)`，没有前进、抓取或投放。`Environment: FAIL` 表示没有球入箱，真正的程序停止原因是模型结果校验异常。

原始失败响应没有被旧日志保存，因此不能逐字段还原那两次输出；日志能够确认 API 返回了 token 用量，失败发生在响应校验阶段。

## 同输入重放复现的具体缺陷

沿用失败调用的图片、prompt、模型及 schema，重放得到：

```json
{"status": "no", "note": "…270 个字符的解释…"}
```

`contracts.py` 将 `Match.note` 限制为最多 240 字符；动作结论本身合法，解释文字超长仍使整个结果失败。校验错误为：

```text
note: string_too_long — String should have at most 240 characters
```

重试时模型改用 61 字符的中文解释，结果通过。该复现证明了“解释长度触发同一停机路径”的接口缺陷，但不代表拿回了原运行丢失的两份坏响应。

证据：`output/langgraph_diagnostics/20261002-112445/responses.json`，对应原始输入在同目录 `input.json`。

## 运动经验存在方向错误

选取第三轮的 `turn_left(0.2)` 样本，直接从两张图片的洋红色箱体像素计算水平中心（没有读取仿真坐标）：

| 来源 | 动作前 x | 动作后 x | 方向 |
| --- | ---: | ---: | --- |
| 箱体像素中心 | 0.497 | 0.635 | 向右 |
| 原运行模型分析 | 0.635 | 0.500 | 向左 |
| 同输入重放 | 0.634 | 0.497 | 向左 |

后端将“当前图”放在第一张，“动作前图”放在第二张，标签为 `current` 和 `comparison`；模型表现出把显示顺序当成时间顺序的混淆。把同一对图改为先 BEFORE 后 AFTER 并明确标注后，单次对照试验判断为向右，但报出的数值是 `0.330 → 0.385`，仍明显偏离像素测量。

所以图片顺序是有证据支持的影响因素，但不能据一次对照就宣称定位精度已经解决。按错误前后坐标计算 `image_rate`，只会把错误分析转换成错误的数值速率。

对照结果：`output/langgraph_diagnostics/20261002-112445/image_order_comparison.json`。

## 定位与匹配还存在不一致

- 原运行转向后可见球的位置已经变化，`find_ball` 仍重复报同一个 `(0.35, 0.22)`，提示旧目标坐标可能被沿用而未重新定位。
- 保存的 reach 多边形在数学上包含 `(0.35, 0.22)`，现有程序匹配函数也返回 yes，但模型文字说它位于区域左侧之外。
- reach 多边形本身也是模型估计，不能因为数学匹配就断言实际可以抓住；当前画面中球仍较远，直接强制 yes 或改用这份区域执行抓取不构成可靠修复。

## 修复应分开处理

1. 对决策字段保留严格校验；解释长度最终按用户要求统一为硬上限 340 字符，超限报错且不截断。
2. 保存失败响应中的结果字段、具体校验位置及原因，并在 GUI 显示实际停止原因；不记录 API 密钥或请求头。
3. 前后图按时间排列并明确标注角色；参考图单独标记，图像去重后也应保留全部角色关系。
4. 核对并使错误运动经验失效，再评估新定位；保护目标身份不等于沿用旧坐标。
5. 用这些真实失败响应补回归用例，并单独评估视觉定位和运动分析模块；之前的模拟响应测试验证了流程分支，没有证明真实模型输出可靠。

## 已实施的修复

- 六种输出结构的 `note` 统一为 340 字符，并在公共短提示中明确字符计数；失败原文、字段位置、实际长度及具体重试反馈均保留。
- 前后图按时间排列，以相机为参考系；历史样本与当前图分别标注，共用图片去重时保留全部角色。
- 寻球、寻箱只接收旧目标身份，不接收旧坐标；每张新图定位后替换当前目标，未知或未见时清空旧位置。
- 旧经验原样归档；旧运动分析失效，reach 保留原图、撤回旧多边形，并在起源阶段重新分析一次，新运动重新采样。
- 修复上下文清洗时误删 `Target.path` 的问题，现在只移除图片本地文件路径。
- GUI 和每集记录增加具体停止原因，校验异常不再只显示 Environment FAIL。
